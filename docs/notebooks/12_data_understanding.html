Appendix B — Data Understanding

what data is available and where it comes from

  • SAP BI extracts serve as the foundation: article, customer, sales & forecast data
  • Data was scoped to finished goods under Make-to-Stock with ambient storage
  • The modeling dataset is based on the top-performing MSO and A-class articles
  • Exploratory analysis confirmed temporal seasonality and product hierarchy depth
  • Data quality is high overall, with minimal missing values and no major outliers

Data Profiling

Character Variables

Table Table B.3 shows the data profiling results for the dataset, including the number of missing values, completeness rate, minimum and maximum length for character variables. The profiling helps identify data quality issues and provides insights into the structure of the dataset.

This data set is of high quality and doesn’t need any further analysis on the character variables.

Numeric Variables

Table Table B.4 shows the data profiling results for the numeric variables in the dataset, including mean, standard deviation, and percentiles. The histogram column provides a visual representation of the distribution of each numeric variable.

We see that the Quantity (Q) needs some further analysis due to outliers.

Article Hierachy

Table Table B.5 summarizes the 4-levels of the article hierarchy by a unique count per level. Roughly,

  • each Family contains roughly 18 articles.
  • each Sub Category contains roughly 4 families.

Summary of Data Understanding

  • The dataset combines master and transactional data from SAP BI and QAD systems.
  • Sales and forecasts are scoped to a single MSO and A-class finished goods.
  • Product and customer hierarchies follow a consistent four-level structure.
  • Exploratory analysis confirms sufficient data volume, patterns, and quality.
  • The data is now ready for scoping, transformation, and modeling.
